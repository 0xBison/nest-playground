# NestJS Playground

A simple NestJS application that i use for testing and experimenting with various features and concepts.

## Quick Start

```bash
# Install dependencies
$ npm install

# Run in development
$ npm run start
# or in watch mode
$ npm run start:dev
# or production mode
$ npm run start:prod
```

## Testing

```bash
# unit tests
$ npm run test
# e2e tests
$ npm run test:e2e
# test coverage
$ npm run test:cov
```
